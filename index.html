How the Aegis AI Works

Each session passes through a five-stage neural pipeline. Every stage is deterministic, observable, and exportable — so analysis can be audited, replayed, and benchmarked against a pro baseline.

Ingest

Video Intake

Player clip is decoded, normalized to a target FPS, and indexed frame-by-frame for downstream alignment.

Vision Model

A CNN detects reticles, HUD state, enemy positions, and input cues using a game-specific weight set.

// yolo-v8 / hud-ocr
03
Align

Pro Baseline Sync

Player frames are temporally aligned with the selected pro's reference run via dynamic time warping.

// DTW · drift <8ms
04
Score

Skill Inference

A transformer scores reaction time, aim stability, decision quality, and positioning against the baseline.

// transformer-skill-v3
05

Findings are merged into a ranked report with timestamped clips, deltas, and prescriptive drills.
